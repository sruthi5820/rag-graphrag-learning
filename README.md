# RAG and GraphRAG Learning Journey

A hands-on Python learning repository covering Retrieval-Augmented
Generation (RAG), GraphRAG, evaluation, production architecture,
optimization, and scaling.

## Learning Objectives

- Understand Python and LLM fundamentals.
- Implement document ingestion and chunking.
- Generate embeddings and perform semantic search.
- Build a complete RAG pipeline.
- Add citations and evaluate answer quality.
- Build knowledge graphs and GraphRAG retrieval.
- Learn production deployment, security, and scaling.

## Repository Structure

- `notes/` - Topic-wise learning notes
- `notebooks/` - Experiments and demonstrations
- `src/` - Reusable Python implementations
- `data/sample_documents/` - Public sample documents
- `tests/` - Unit and integration tests
- `diagrams/` - Architecture diagrams
- `projects/capstone/` - Final project

## Learning Method

Each topic includes:
1. Theory and definitions
2. Architecture or workflow
3. Python implementation
4. Practical exercise
5. Testing and observations
6. Learning summary
